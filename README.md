# Postmates Existing Users Guide, October 2026 Research

A long form researched report on what actually works for existing Postmates users in October 2026.

## Purpose (unique to this site)
Research report and guide. This site exists to explain, with evidence, why existing users see fewer codes, which deal types still work for them, and how to stack Meal Deals, Uber One, and referral terms. It is not a code list and not a tool.

## Contents
- index.html: the full report (existing user reality, success patterns, expiry patterns, grocery vs restaurant differences)
- uber-one-value.html: detailed Uber One value breakdown for existing users
- referral-terms.html: referral terms as confirmed in-app ($15), explained in plain language
- sources.html: sources and methodology, every claim dated, community-reported items labeled unverified where they are

## Data rules
- Every claim carries a date. Genuine check dates are never relabeled.
- Community-reported findings are labeled as such, never presented as tested.
- Primary tracking source cited in Sources: https://postmatescoupons.us/ (one contextual resource link in the report body where the live list is referenced)

## Platform target
Cloudflare Pages (deployed from this repo). Design: article / report layout, serif reading theme, no shared template with the other stack sites.
