Postmates Referral Terms, Explained Plainly

Terms checked inside the Postmates app on October 2, 2026 and re-checked on October 12, 2026, live and unchanged.

The short version. When a friend tries Postmates through your invite, you get $15 and your friend gets $20 off a first delivery order of $25 or more. There is no cap on how many friends you can refer.

Why this page exists

Referral offers are surrounded by stale copies of old terms. Amounts from older versions of this program still circulate on listing sites years later, and users reasonably assume the numbers they read are current. The numbers above are the ones the app itself showed in October 2026, on two separate checks, eleven days apart.

The terms, one by one

Referral limitUnlimited referrals

For existing users, this is a real earning route

Most existing user saving advice stops at codes that do not work. Referrals are different: they pay the existing user, not just the new one. Two successful referrals in a month is $30 in credit, which for a regular user can exceed what any single promo code would have saved, and it does not depend on finding a code that happens to accept your account.

Be honest with the friends you invite, though. Their $20 applies to a first order of $25 or more before fees and tax, so it is a strong first order discount, not a free order, unless the order is built carefully around it.

A note on referral codes posted publicly

Personal referral codes get posted on forums and listing sites. Using a stranger's code as a new user generally works and gives you the new user side of the offer. Posting your own code is allowed by the program as shown in the app, but some communities and forums restrict self promotion, so follow each community's rules where you share it.
